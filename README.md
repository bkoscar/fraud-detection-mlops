# fraud-detection-mlops
End-to-end Fraud Detection project with full MLOps stack: data pipelines, reproducible training, FastAPI serving, Docker, MLflow, and monitoring.

Proyecto educativo/profesional para construir un sistema de detección de fraude en tarjetas de crédito con prácticas de MLOps:

- Ingestión y procesamiento de datos.
- Entrenamiento reproducible de modelos.
- Despliegue de un servicio de inferencia (API REST) en contenedores.
- Tracking de experimentos con MLflow.
- Monitoreo de rendimiento y data drift.
- Plan de reentrenamiento automatizado.
